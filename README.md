# Etch-A-Sketch
## Foundations: Project

Etch-a-sketch contains a canvas of divs which change color when hovered.
This version of Etch-a-sketch implements the following:
- A `16x16` grid of square divs.
- When hovered, the divs beneath the cursor change color and opacity, allowing users to create a sketch.
- 10 opacity levels, 0 to 1.
- Each `div` initially gets a `selected` or `random` color when hovered. 
- There are 8 colors to select and sketch from.
